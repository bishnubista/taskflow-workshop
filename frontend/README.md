# TaskFlow Frontend

React + Vite frontend for the TaskFlow workshop demo.

## Setup

```bash
cd frontend
npm install
```

## Development

Make sure backend is running first:
```bash
cd ../backend
npm run dev
```

Then in a new terminal:
```bash
cd frontend
npm run dev
```

Frontend runs on http://localhost:5173

## Building

```bash
npm run build
```
