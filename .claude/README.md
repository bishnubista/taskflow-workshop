# Claude Code Context Files

This directory contains context files that help Claude Code understand the project better.

## Files in this directory

### `CONTEXT.md`
Project context that Claude Code reads to understand:
- Project structure and architecture
- Coding conventions and patterns
- Key constraints and requirements

### `settings.local.json`
Permissions configuration for Claude Code:
- Which tools Claude can use
- Safety restrictions
- Workflow preferences

## Why Context Engineering Matters

Claude Code is most effective when it has the right context. These files help:

1. **Reduce repetition**: No need to explain the same things repeatedly
2. **Maintain consistency**: Claude follows established patterns
3. **Improve accuracy**: Better understanding = better suggestions
4. **Speed up development**: Less back-and-forth clarification

## Demo-4 Focus

In demo-4, we showcase how proper context engineering enables Claude Code to:
- Plan complex features with full system understanding
- Suggest improvements aligned with project goals
- Implement features that integrate cleanly with existing code
- Make architectural decisions based on project constraints
